### 👋 Sobre mí

Soy Javier, estudiante de ingeniería informática con interés en la intersección entre hardware, software y ciencia aplicada. Me gusta explorar cómo los sistemas físicos y los protocolos de red se combinan para crear soluciones reales, eficientes y escalables.

- 🔧 Sistemas empotrados y microcontroladores
- 🌐 Redes, protocolos y comunicaciones
- ⚛️ Computación cuántica y conceptos avanzados de informática
- 🧠 Desarrollo de soluciones prácticas con electrónica, software y automatización
